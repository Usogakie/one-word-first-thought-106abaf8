One word, first thought: a tiny Python program that writes a single word — "syzygy", the alignment of three celestial bodies — to `entry.txt`. Surprising, vivid, and chosen, not generic.

## Run it

```sh
python3 main.py
```

The program writes the word to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt`.
